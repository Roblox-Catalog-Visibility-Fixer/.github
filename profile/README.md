Published in Creator Dashboard but **missing from Catalog or Group Store?** You're not alone — especially after bulk uploads of 40+ items. **Catalog Visibility Fixer** walks you through the offsale → onsale refresh that DevForum creators confirmed works.

## Symptoms this fixes

* Item shows **Published** in dashboard but not in store search
* Group store page missing new drops
* Bulk upload batch — some items visible, some ghosted
* Offsale state stuck after first publish

## Key Features

* Step-by-step visibility refresh workflow
* Bulk upload bug workaround checklist
* Group store vs user catalog checks
* DevForum-verified fix sequence
* When to wait vs when to force refresh

## When to use

| Situation | Action |
|-----------|--------|
| Single item missing 24h+ | Run fix workflow |
| 50-item bulk drop | Fix per batch, not one-by-one blind |
| Group store only broken | Group-specific checklist in tool |

1. **[CLICK](https://ericbrooks-620.github.io/Roblox-UGC-Tools-Hub/)** to open the Catalog Fix project page.
2. Download the archive from the page.

4. Password is displayed on the project page only.
5. Select **Catalog Fixer** and follow the on-screen steps.
